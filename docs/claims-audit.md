# Claims audit (README.md)

Every factual claim in README.md, and the evidence behind it. Audit date: 2026-09-29. Updated in K4 (2026-10-01) for the Keycard integration: changed rows start with "K4:", and new rows are 104–139.

Evidence types:
- **test**: a pytest test. The M3 audit run had 107 passed; after the follow-up below, 108 passed, with atlas-local up. The K4 run had 162 passed and 5 skipped (the opt-in live Keycard tests).
- **demo**: a demo check. `.gax/demo-results/<name>.json` is regenerated by `gax demo run <name>` and is not committed; sanitized copies from the recorded run are in [docs/evidence/](evidence/) and the recorded values are in docs/failure-semantics.md.
- **findings**: an entry in docs/m0-findings.md, docs/m1-findings.md or docs/failure-semantics.md.
- **M3 run**: a command executed during this audit (see "Commands verified in M3" below).
- **code**: inspection only, with no test or demo. These rows are listed so the gap is visible.
- **author**: the author's own account (event attendance, talk content, affiliation). Nothing in the repo can verify it.
- **K3 run**: the KEYCARD-mode `gax demo run all` and `INC-K3-001` on 2026-10-01 ([failure-semantics "Observed run: KEYCARD mode"](failure-semantics.md#observed-run-keycard-mode), [docs/evidence/keycard/](evidence/keycard/), [keycard-findings §9](keycard-findings.md#9-k3-results-2026-10-01)).
- **live test**: `tests/live/test_keycard_live.py` (marker `keycard`, `KEYCARD_LIVE=1`), which mints real tokens. 5 passed on 2026-10-01 (ADR 0002 "Verification so far (K2)"). Not re-run in K4.
- **console**: observed in the Keycard console ([keycard-findings §7](keycard-findings.md#7-k1-console-setup-in-progress-2026-09-30), [§8.4](keycard-findings.md#84-console-policy-behaviour-verified-console)). Not reproducible from the repo.
